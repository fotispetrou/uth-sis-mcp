# uth-sis-mcp

MCP server για την Ηλεκτρονική Γραμματεία (SIS-Web, sis-web.uth.gr) του
Πανεπιστημίου Θεσσαλίας. Συνδέεται με τον λογαριασμό σου και δίνει σε ένα
πρόγραμμα AI (Claude Desktop, Claude Code, Cursor κ.ά.) πρόσβαση στα:

- στοιχεία φοιτητή: ΑΜ, τμήμα, πρόγραμμα σπουδών, εξάμηνο
- πρόοδος: μέσος όρος, περασμένα μαθήματα και ECTS, ECTS εξαμήνων 1–6
- η καρτέλα σου, με τον βαθμό κάθε μαθήματος
- όλες οι προσπάθειες σε εξετάσεις, ανά μάθημα ή εξεταστική
- το πρόγραμμα σπουδών, με το τι έχεις περάσει και τι χρωστάς
- περίοδοι δηλώσεων μαθημάτων, αν είναι ανοιχτές και τι έχεις δηλώσει
- ανακοινώσεις της Γραμματείας

Μόνο διαβάζει. Δεν κάνει δηλώσεις και δεν αλλάζει τίποτα. Το SIS-Web έχει μια
παγίδα: αν ανοίξεις μια δήλωση που έχεις ήδη υποβάλει, γίνεται ξανά «Πρόχειρη»
και πρέπει να την υποβάλεις από την αρχή. Γι' αυτό ο server δεν πλησιάζει
καθόλου τη σελίδα επεξεργασίας της δήλωσης. Οι δηλώσεις γίνονται από το site.

## VPN

Το SIS-Web ανοίγει μόνο μέσα από το δίκτυο του Πανεπιστημίου ή με το VPN του.
Αν δεν απαντάει, ο server ζητάει από το OpenVPN GUI να συνδέσει το προφίλ
«UTH Intranet» και συνεχίζει μόλις ανέβει (Windows). Για να γίνεται χωρίς
ερώτηση, συνδέσου μία φορά από το OpenVPN GUI τσεκάροντας «Save password».

## Εγκατάσταση

Χρειάζεται Python 3.10 ή νεότερο και το [uv](https://docs.astral.sh/uv/).

```
git clone https://github.com/fotispetrou/uth-sis-mcp
cd uth-sis-mcp
uv sync
```

## Στοιχεία σύνδεσης

Είναι τα ίδια με του eClass. Αποθήκευσέ τα μία φορά στον κωδικοφύλακα του
συστήματος (στα Windows είναι το Credential Manager):

```
uv run uth-sis-mcp login
```

Εναλλακτικά βάλε τα στις μεταβλητές περιβάλλοντος `UTHSIS_USERNAME` και
`UTHSIS_PASSWORD`. Ο κωδικός πηγαίνει μόνο στην κεντρική σελίδα εισόδου του
Πανεπιστημίου (cas.uth.gr).

Δοκίμασε ότι όλα δουλεύουν (δεν αλλάζει τίποτα):

```
uv run uth-sis-mcp check
```

## Σύνδεση με Claude Desktop ή Cursor

Στο αρχείο ρυθμίσεων (`claude_desktop_config.json` ή `mcp.json`) πρόσθεσε:

```json
{
  "mcpServers": {
    "uth-sis": {
      "command": "uv",
      "args": ["--directory", "C:/path/to/uth-sis-mcp", "run", "uth-sis-mcp"]
    }
  }
}
```

Για Claude Code:

```
claude mcp add uth-sis -- uv --directory C:/path/to/uth-sis-mcp run uth-sis-mcp
```

Μετά ρωτάς απλά: «πόσα ECTS έχω;», «τι χρωστάω από το 4ο εξάμηνο;», «έχω κάνει
δήλωση μαθημάτων;», «τι πήρα στον Σεπτέμβρη;».

## Εργαλεία

| εργαλείο | τι κάνει |
| --- | --- |
| `whoami` | στοιχεία φοιτητή, και έλεγχος ότι η σύνδεση δουλεύει |
| `get_progress` | μέσος όρος, περασμένα μαθήματα και ECTS, ανά εξάμηνο |
| `get_transcript` | η καρτέλα: κάθε μάθημα με βαθμό και ECTS |
| `get_grades` | όλες οι προσπάθειες, φίλτρο ανά μάθημα ή εξεταστική |
| `get_curriculum` | το πρόγραμμα σπουδών με το τι έχεις περάσει |
| `get_registration_periods` | περίοδοι δηλώσεων και αν είναι ανοιχτές |
| `get_registration` | τι είναι δηλωμένο σε μια περίοδο και σε τι κατάσταση |
| `get_announcements` | ανακοινώσεις της Γραμματείας |

## Ρυθμίσεις

Αν ο λογαριασμός σου έχει πολλά προφίλ (π.χ. και Παιδαγωγική Επάρκεια),
χρησιμοποιείται το ενεργό με το πιο πρόσφατο εξάμηνο. Άλλο διαλέγεις με τη
`UTHSIS_PROFILE` (κωδικός ή όνομα τμήματος). Με `UTHSIS_AUTO_VPN=0` δεν
ανοίγει μόνο του το VPN, και με `UTHSIS_VPN_PROFILE` ορίζεις άλλο προφίλ του
OpenVPN.
